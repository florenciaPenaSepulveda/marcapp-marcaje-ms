# marcapp-marcaje-ms

Microservicio de marcaje de asistencia de Marcapp.

## Tecnologías

- NestJS
- TypeScript
- TypeORM
- PostgreSQL
- MySQL
- Jest

## Estructura

```
📄 README.md
📄 nest-cli.json
📄 package-lock.json
📄 package.json
📁 src
📁 test
📄 tsconfig.build.json
📄 tsconfig.json
```

## Cómo ejecutarlo

```bash
npm install
npm run start:dev
npm start
npm run build
npm run test
```

## Variables de entorno

Copia `.env.example` a `.env` y completa los valores (el `.env` real no se versiona):

- `APP_PORT`
- `EXPO_PUBLIC_MS_USER_URL`
